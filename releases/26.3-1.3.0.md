- Netherite tools and armor can be repaired on an anvil with diamonds or netherite scraps
- Each diamond restores half as much durability as a normal repair material, so a full repair takes twice as many diamonds
- Each netherite scrap restores twice as much durability, so a full repair takes half as many scraps
- Netherite ingots still repair netherite gear at the previous rate
- Enchanted gear can spend extra materials to finish a repair when one material no longer restores enough durability
